# StudyFlow

StudyFlow é uma plataforma de gerenciamento de estudos desenvolvida como projeto de aprendizado e portfólio. O objetivo é construir uma aplicação próxima de um produto real, aplicando boas práticas de desenvolvimento, arquitetura de software e organização de código.

O projeto busca oferecer uma forma simples de organizar tarefas, acompanhar metas e visualizar a evolução dos estudos, ao mesmo tempo em que serve como um ambiente para aprofundar conhecimentos em desenvolvimento backend.

---

## Objetivos

* Desenvolver uma API REST utilizando FastAPI.
* Aplicar princípios de arquitetura de software.
* Construir uma aplicação escalável e organizada.
* Praticar integração entre frontend e backend.
* Utilizar ferramentas modernas do ecossistema Python.
* Documentar toda a evolução do projeto.
